# Pandas Data Analysis & Customer Purchase Insights

This project demonstrates core data manipulation and analysis workflows using Python's **Pandas** library[cite: 1]. It covers reading various file formats, slicing data, applying simple and complex queries, merging datasets, and aggregating customer spending behaviors[cite: 1].

##  Features & Workflow

1. **Data Reading**: Importing data from `.csv`, `.table` (tab-separated), and `.txt` (fixed-width) files[cite: 1].
2. **Data Slicing & Selection**: Indexing rows and columns using `.iloc[]`, `.loc[]`, and boolean masks[cite: 1].
3. **Querying & Filtering**: Filtering dataset records based on demographics and purchase criteria[cite: 1].
4. **Data Merging**: Joining client demographic profiles with transaction logs via primary/foreign keys (`CUSTOMER_ID`)[cite: 1].
5. **Aggregation & Insights**: Grouping expenditure data to identify top spenders and itemized purchase histories[cite: 1].
6. **Data Export**: Saving processed results back into `.csv` and `.xlsx` formats[cite: 1].

##  Tech Stack

- **Python 3.x**
- **Pandas**
- **OpenPyXL** (for Excel file exports)

##  Sample Insights

- Joined customer data with purchase logs to aggregate total spending per customer[cite: 1].
- Identified top purchasing clients along with their distinct item purchasing history[cite: 1].
- Exported processed results to `top_spenders.csv` and `sales_record.xlsx`[cite: 1].
